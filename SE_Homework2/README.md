# 一箭又一箭

## 项目简介

使用 Python 和 Pygame 开发的点击式箭头解谜小游戏。玩家需要按照合适的顺序点击箭头，使所有箭头依次飞出棋盘。

## 游戏规则

- 棋盘采用 `6 × 6` 网格。
- 箭头方向包括上、下、左、右四种。
- 点击箭头后，检查它前进方向至棋盘边界之间是否存在其他箭头。
- 前方没有阻挡时，箭头飞出棋盘并消失。
- 前方存在阻挡时，箭头不能消失，显示碰撞反馈，并消耗一次失误机会。
- 清除当前关卡全部箭头后通关并进入下一关。
- 失误次数耗尽后本关失败，可以重新开始。

路径检测规则如下：

- 向上：检查同列上方的格子；
- 向下：检查同列下方的格子；
- 向左：检查同行左方的格子；
- 向右：检查同行右方的格子。

## 最小可行版本

第一版计划实现：

- 开始界面、游戏界面、通关界面和失败界面；
- 鼠标点击箭头；
- 四方向箭头绘制；
- 路径阻挡检测；
- 箭头飞出和碰撞反馈；
- 剩余箭头数和失误次数显示；
- 重新开始当前关卡；
- 至少 3 个固定且可以正常通关的关卡。

暂不实现计时、得分、随机地图、撤销操作、AI 自动求解和音效等扩展功能。

## 开发环境

- Python 3.13+
- Pygame
